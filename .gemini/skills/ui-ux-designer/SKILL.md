# Core Mandates for Frontend Redesign
- **Visual Style:** Adhere to a clean, modern, travel-magazine aesthetic. Use crisp typography (Inter/SF Pro), ample whitespace, and soft shadows over hard borders.
- **Layout Structure:** Shift from rigid vertical lists/tables to dynamic, responsive grid card layouts.
- **Color Weights:** Use high-contrast primary actions for booking/adding itinerary events and neutral, muted tones for secondary metadata.
- **Component Rules:** Always ensure interactive elements have a clear `:hover` state and explicit tap targets (44x44px minimum) for mobile responsiveness.
